# BrigadaDrones-ejemploOrtofoto
Este es un ejemplo de las fotos a capturar para generar una ortofoto.

Se debe procesar en una herramienta que permita tomar las fotos y generar la ortofoto, proceso que consiste en coser las fotos y les quita la perspectiva a los edificios.

Existe una herramienta de código abierto que se llama OpenDroneMap, que puedes instalar en tu computador (necesita linux y docker).
La comunidad de OSM Latam tiene una instancia pública que puedes usar: https://opendrone.osm.lat/

Escríbele a AngocA para pedir un usuario.
