# BrigadaDrones-ejemploOrtofoto
Este es un ejemplo de las fotos a capturar para generar una ortofoto.

Se debe procesar en una herramienta que permita tomar las fotos y generar la ortofoto, proceso que consiste en identificar elementos comunes entre fotos, coser las fotos y quitar la perspectiva a los edificios.

Existe una herramienta de código abierto que se llama OpenDroneMap, que puedes instalar en tu computador (necesita Linux y Docker).
La comunidad de OSM Latam tiene una instancia pública que puedes usar: https://opendrone.osm.lat/. Puedes solicitar tu usuaior con @AngocA.
